## 📦 Setup
### 🚀 Installation
```bash
git clone https://github.com/TZevs/VehicleRentalSystem.git
```
### Usage
1. Open folder `VehicleRentalSystem/VehicleRentalApp` in Visual Studio.
2. Double Click the `VehicleRentalApp.sln` in the Solution Explorer on the right-hand side.
3. Press Run
